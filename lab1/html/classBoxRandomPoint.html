Подробное описание

Класс для генерации случайных точек в параллелепипеде

Класс позволяет генерировать случайные точки в заданной области, ограниченной параллелепипедом. Поддерживает возможность задания плоских областей (когда min == max по некоторой координате) Использует динамическое выделение памяти через указатели
